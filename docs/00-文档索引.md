## 需求要点速览（供快速对齐）

### 系统定位
从真实业务平台获取中标订单及特征 → 算出欠费风险概率 → 按可配置的风险档规则生成催收任务并分配给催收员 → 辅助话术生成 → 数据大盘监控。

### MVP 聚焦
**催收任务 + 话术闭环**。数据全 mock，预测算法暂不实现（预留接口）。

### 风险档与催收节奏（可配置，默认）
| 风险档 | 概率阈值 | 催收时点（中标后第 N 天） | 场景 |
|--------|---------|--------------------------|------|
| 高 | ≥ 70% | 7 / 15 / 30 | 首催/二催/三催 |
| 中 | 30%~70% | 30 | 首催 |
| 低 | < 30% | 90 | 首催 |

> 触发条件：到达催收时点**且届时仍未支付**才生成实际催收任务。

### 技术栈
- 后端：Python + FastAPI + SQLAlchemy + APScheduler
- 前端：React + TypeScript + Vite + Ant Design
- 数据库：PostgreSQL（开发期 SQLite）
- LLM：Provider 抽象层（Claude / OpenAI / mock，可开关）

### 关键设计原则
- **风险算法可替换**：Mock Provider → Algorithm Provider，调用方无感知
- **LLM 可降级**：AI 话术失败时回退模板，不阻断催收
- **数据源可演进**：CSV 上传 → 真实平台 API
- **配置可视化**：阈值、催收时点、话术模板后台可配，无需改代码
